# DAPA LAW MCP

방위사업청 업무에 필요한 법령, 행정규칙 및 공개 법령정보를 공식 출처에서 조회할 수 있도록 돕는 MCP 서버입니다.

이 서비스는 국가법령정보센터 공동활용 Open API와 방위사업청 공개 자료를 연결합니다. 답변은 업무 검토를 위한 참고자료이며, 최종 판단과 결재는 담당자가 공식 원문을 확인해 수행해야 합니다.
