## 확인된 원인

이번에 추적한 최근 사건은 **법제처 공개 API에서 노출되지 않는 문제와, MCP에 다른 공식 원문 경로가 없던 문제가 함께 작용했다.** 검색어를 넓히거나 본문 조회 개수를 늘리는 것만으로 아래 세 사건을 복구할 수는 없었다.

[공식 판례 목록 API 가이드](https://open.law.go.kr/LSO/openApi/guideResult.do?htmlName=precListGuide)에 따른 사건번호 전용 조건 `nb`로 MCP를 거치지 않고 직접 조회했다. 모두 HTTP 200이었고, 대조군 사건은 정상 반환됐다.

| 2023나2038708 | 0건 | 위 대법원 원문의 원심 사건번호이며 공식 공시에도 등장 |
| 2022가합534725 | 0건 | 거래소 공시의 방위사업청 상대 소송 항목에 등장 |

따라서 정확한 표현은 **“현재 공개 API의 사건번호 검색에 노출되지 않는다”**이다. 법제처 내부 저장 여부, 향후 반영 여부, 모든 관련 판례의 미존재를 뜻하지 않는다. 후보 본문 조회 한도 때문에 다른 사건을 놓칠 가능성과도 구분해야 한다.

기존 MCP에는 사건번호 전용 `nb` 조회가 없고 제목·본문 검색만 있었다. 또한 법제처 API만 조회해, 법원에 공개된 원문으로 이어지는 경로가 없었다. 이 두 구조를 보완했다. `search=3`은 사건번호 전용 검색이 아니라 참조판례 검색이므로 대체 수단으로 사용하지 않았다.

법원 판결문은 회사명을 익명 처리하고 있으므로 **판결문 단독으로 방위사업청 당사자 관계까지 인증했다고 표현하지 않는다.** 방위사업청 관련성은 같은 원심 사건번호를 가진 공시의 설명으로 대조했다. 공시의 회사 설명과 법원의 사실인정·판시는 다른 종류의 근거다.

KIND의 경로에 있는 문서번호를 DART 접수번호로 그대로 바꾸면 다른 회사의 공시가 나온다. 이번에는 DART 공식 회사별 검색에서 실제 접수번호를 찾아 본문과 사건번호를 대조했다. 단순 번호 변환은 구현하지 않았다.

## 원문에 근거한 직원 답변 예시

**질문:** 방위사업청 납품계약에서 지체상금을 감액한 판례가 있나요?

**답변:** 대법원 2026.4.30. 선고 **2024다272736** 판결서를 확인했습니다. 원심은 작업중지명령에 이르게 된 경위와 기간 등을 고려해 지체상금 중 **20%를 감액**했고, 대법원은 그 판단에 법리오해가 없다고 보았습니다. 80% 감액이나 전액 면제로 설명하면 안 됩니다.

다만 이 사건 물품대금의 **지연손해금률**에 대해서는 계약 특수조건에 따른 금융기관 대출평균금리를 적용해야 한다고 판단해 그 부분을 파기환송했습니다. 지체상금 감액과 대금 지급 지연에 따른 이자 문제는 구분해야 합니다. 같은 원심 사건번호를 가진 공식 공시에는 방위사업청의 지체상금 부과와 감액 소송으로 설명돼 있습니다. 이 부분은 회사 공시에 따른 사실관계 설명이며 법원 판시와 출처를 나눠 제시합니다. 다른 계약에 같은 감액률이나 면제가 자동 적용된다는 뜻은 아닙니다.

원문 대조 위치:

- PDF 1쪽: 주사건번호·선고일·원심 사건번호.
- PDF 2쪽: “원고가 부담해야 할 지체상금 중 20%를 감액하였다”, 해당 비율 판단에 법리오해가 없다는 판단.
- PDF 2~3쪽: 특수조건 제9조제1항과 국가계약법 시행령 제58·59조에 따른 지연손해금률.
- DART `우발부채 등에 관한 사항`의 위 소송 항목: 방위사업청 관련 공시상 설명.

공식 PDF의 주문과 이유에는 환송 법원 표기가 일치하지 않는 부분이 있어, 여기서는 특정 법원명을 확정하지 않고 **“지연손해금 부분 파기환송”**으로 설명했다. 원문을 임의로 고치지 않았다.

## 적용한 서비스 보완

- 판례 사건번호 전용 조회와 엄격한 단독 사건번호 자동 인식, 사건번호를 포함한 캐시 키, `case_number` 검색 범위 표시를 추가했다.
- 지체상금 본문 검색에 법원 공식 공개 판결문 경로를 연결했다. 게시판의 EUC-KR 인코딩과 ‘지연배상금’ 표현을 처리한다.
- 공개 게시글의 첨부 PDF를 실시간으로 내려받아 주사건번호를 실제 본문과 대조한다. 파일명이나 인용된 다른 판례 번호만으로 인증하지 않는다. 실제 PDF 표 구조의 `사 / 사건번호 / 사건명 / 건` 형태도 처리한다.
- 공식 원문 URL·첨부 URL·선고일·쪽수·SHA-256·잘림 여부를 반환한다. 반환된 `court:` 문서 ID로 전체 상세를 다시 조회할 수 있다.
- KIND·DART의 공시 문맥 조회 도구를 추가했다. 공시 원문 주소·매개변수는 허용된 공식 범위로 제한하고, 회사 공시라는 근거 종류를 명시한다. 공시 URL 탐색 전체를 자동화한 것은 아니며 확인된 공식 URL을 입력한다.
- 장애·시간 초과·접근 거절은 검색 0건과 구분한다. 공개 API에서 해당 사건번호가 조회되는지도 별도 진단 정보로 반환한다.
- 전체 검색 deadline 안에서 법원 경로를 수행하며, 법원 검색은 게시물 일부·첨부 PDF 최대 1건으로 제한한다. 이는 법원 전체 판례 검색이 아니다.
- 서로 다른 직원 질문이 같은 원문을 찾으면 프로세스 내 원본 캐시와 진행 중 요청을 공유한다. PDF 다운로드·변환에는 프로세스 내 동시 처리 2개·대기 32개 제한을 적용했다. 분산 전체 시스템의 동시접속 SLA 보장은 아니다.
- 법령만 지정한 질문에는 법원 경로를 추가하지 않는다. 지원하지 않는 판례 기준일 상세조회는 외부 요청 전에 거절한다.

기존 MCP 주소는 `https://dapa-law-mcp.vercel.app/law`로 유지한다. 새 도구는 `search_official_court`, `read_official_case_context`다. 법원 경로는 운영 설정에서 기본 활성화되며 `COURT_OFFICIAL_FALLBACK_ENABLED=0`으로 비활성화할 수 있다.
