# 개인정보처리방침

시행일: 2026년 9월 2일

DAPA LAW MCP 운영자(이하 “운영자”)는 방위사업 관련 법령정보를 조회하는 MCP 서비스를 제공하며, 이용자의 개인정보를 최소한으로 처리합니다. 이 방침은 운영자가 직접 운영하는 서비스의 처리 기준을 설명합니다.

## 1. 처리하는 정보

서비스는 회원가입, 결제, 광고 목적으로 개인정보를 요구하지 않습니다. MCP 요청을 처리하는 과정에서 다음 정보가 일시적으로 처리될 수 있습니다.

- 이용자가 입력한 법령·행정규칙 검색어와 요청 내용
- MCP 연결에 필요한 요청 시각, 오류 유형, 네트워크·브라우저 등 기술 정보
- 서비스 안정성, 보안, 장애 대응을 위해 호스팅 사업자가 자동 생성하는 접속·실행 로그

주민등록번호, 비밀번호, 결제정보와 같은 민감한 정보는 입력하지 마십시오.

## 2. 처리 목적

- 국가법령정보센터 공동활용 Open API와 방위사업청 공개 자료 조회
- 검색 결과의 본문·조문·출처·기준일 제공
- 장애 확인, 보안 유지, 사용량 및 성능 관리

## 3. 보관 및 파기

운영자는 이용자별 계정이나 검색 이력을 자체 데이터베이스에 저장하지 않습니다. 서버의 일시적 캐시는 최신 응답 재사용을 위해 제한된 시간 동안만 유지되며, 실행 환경이 종료되거나 만료되면 삭제됩니다.

Vercel 등 호스팅 사업자의 인프라 로그와 국가법령정보센터 API의 로그는 각 사업자의 정책과 법령에 따라 보관될 수 있습니다. 운영자는 해당 로그를 별도 목적의 이용자 프로파일링에 사용하지 않습니다.

## 4. 제3자 제공 및 외부 전송

검색어와 API 조회에 필요한 요청은 다음 외부 서비스로 전송될 수 있습니다.

- 국가법령정보센터 공동활용 Open API: 법령·행정규칙·판례 등 공식 자료 조회
- Vercel: MCP 서버 호스팅과 요청 처리

운영자는 개인정보를 판매하거나 광고 목적으로 제공하지 않습니다. 외부 서비스의 처리 방식은 각 서비스의 개인정보처리방침이 적용됩니다.

## 5. 이용자 권리와 문의

개인정보 처리에 관한 문의, 열람·정정·삭제 요청은 [DAPA MCP 저장소의 문의 창구](https://github.com/ai-studying-man/DAPA-MCP/issues)를 통해 접수할 수 있습니다. 공개 게시판에는 주민등록번호, 연락처, 내부 문서 등 민감한 정보를 게시하지 마십시오.

## 6. 방침의 변경

법령, 서비스 구성 또는 외부 API 정책이 변경되면 이 페이지의 시행일과 내용을 갱신합니다. 중요한 변경은 저장소 변경 이력 또는 서비스 안내를 통해 알립니다.
