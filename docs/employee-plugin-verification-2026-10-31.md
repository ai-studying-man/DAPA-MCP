2. 중복 사건: 법원과 사건번호가 모두 확인된 경우 동일 사건의 다른 문서 ID를 합치고, 본문 집중 검색의 우선순위를 보존한다. 법원명 또는 사건번호가 없으면 ID로 구분한다.
3. 단순 단어 동시 출현을 직접 판례처럼 오해하던 문제: `direct_defense`를 `defense_context`로 바꿨다. 방산 지체상금은 실제 판단의 연관성을 자동 확정할 수 없어 보수적으로 partial을 반환한다. 실제 직접 판례가 들어와도 자동으로 grounded 승격하지 않으며 원문 검토가 필요하다.

방위력개선사업은 군사력을 개선하기 위한 사업의 범위이고, 군수품 조달은 군이 사용할 물품을 확보하는 활동입니다. 제3조제1호는 무기 구매·개발·성능개량과 관련 시설을, 제2호는 무기체계와 전력지원체계인 군수품을, 제5호는 구매·연구개발·생산을 통한 조달인 획득을 정합니다. 따라서 두 개념은 겹칠 수 있습니다. 제25조는 조달계획 수립과 방위사업청 일괄조달 원칙 및 각군·조달청을 통한 예외를 정합니다. 물품을 산다는 이유만으로 모든 조달을 방위력개선사업이라고 단정해서는 안 됩니다.

## 직접 판례 확인의 남은 한계

5번 질문에서 자연어 검색으로 대법원 95다11436(1996-04-26, ID198059)을 찾고 상세 원문까지 실제 플러그인으로 확인했다. 별도 방위산업물자 계약과 관급 선박 계약의 구분, 감액 사유와 주문을 함께 읽었다. 방위산업체 관련 실제 지체상금 감액 판례이지만 현행 방위사업청 방산물자 계약의 직접 판례라고 표현하지 않았다. 자동 인용 확인은 동일 사건번호의 복수 문서 때문에 AMBIGUOUS였으며, ID198059 상세의 법원·사건번호·선고일·주문을 수동 대조했다. 이 중복 후보 인용 판별은 추가 개선 대상이다.

추가 원인 조사에서 ‘지체상금 방위사업청’ 본문 검색 7건은 실제 지체상금 판단이 아닌 정산·하자·관할·노동 등의 사건이었다. 이는 그 검색 범위의 결과이며 직접 판례 자체가 없다는 증거는 아니다. 직접 판례 검증을 완성하려면 정확한 사건번호의 공식 원문을 추가 확보하여 사실관계와 판단을 대조해야 한다. 현재 제한된 탐색은 전수 조사나 모든 판례의 미존재 판단이 아니다.

7·8번 조례의 API 상태는 unknown이었다. 조회된 조문을 근거로 답했지만 오늘의 현행성까지 검증됐다고 말하지 않았다. 조례 지원사업 공고·보조금 위임 조례, 개별 제재의 현행 적용 법령과 사실관계도 별도 확인 대상이다.
